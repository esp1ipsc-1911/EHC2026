# EHC 2026 — Stage Analysis
### Classic Division · 10-round magazines

A tactical stage analysis tool for all 24 stages of the **European Handgun Championship 2026**.

Built for **Classic Division** competitors using 10-round magazines.

---

## Features

- All 24 stages with full tactical analysis
- **Overlay** on original stage diagrams showing:
  - Numbered shooting order steps
  - Reload points
  - Movement arrows
  - NS target warnings (red markers)
  - Moving target activation arrows
- Magazine load plans (Classic / 10-round)
- Filter by: Special Constraints | Moving Targets | Long Stages | 3+ Reloads
- Works offline — no server required

---

## How to use

### Option 1 — Open locally
Just open `index.html` in any modern browser. No server needed.

### Option 2 — GitHub Pages
1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, root `/`
4. Your site will be live at `https://yourusername.github.io/ehc2026/`

## Key rules (Classic Division reminder)

- Maximum **10 rounds per magazine**
- **Minimum round rule**: all scoring targets must be engaged
- **NS targets**: engaging an NS target scores as a miss on that target
- **Disappearing targets**: once gone, points cannot be recovered
- **Weak/Strong hand**: violation = procedural penalty per occurrence
